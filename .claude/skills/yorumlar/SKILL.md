# /yorumlar

`videolar/*/yukleme.json` içindeki yayınlanmış videolar için `topluluk-yoneticisi` çalışsın. Kullanıcıya Türkçe: ana 3 konu, kopyalayıp yapıştıracağı en önemli 3 yanıt (İngilizce, kod bloğunda), yeni video fikirleri. Yanıtları kullanıcı YouTube Studio → Yorumlar'dan gönderir.
