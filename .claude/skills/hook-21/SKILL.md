# Hook-21

Formulas: [formuller.md](formuller.md). Read it first.

1. Take the title's promise. The hook must confirm it within 20 seconds.
2. Check `kanal/ogrenme-kaydi.md` for formulas that worked; reuse one winner, but try at least one new formula each video.
3. Draft **3 hooks** from 3 different formulas: ≤ 2 sentences of promise + 1 credibility line ("Here's what the annual report actually shows.") + 1 open loop.
4. Score 1-5: Clarity (understood in 3 s) · Curiosity · Specificity (number, name, object) · Package fit (confirms title without repeating it) · Spoken rhythm.
5. Use the highest scorer in `senaryo.json` s01-s03; record the formula number in `hook_formulu`.

Never open with "Hey guys", "In this video", "Welcome back". No promise the video doesn't deliver. Numbers must be sourced.
